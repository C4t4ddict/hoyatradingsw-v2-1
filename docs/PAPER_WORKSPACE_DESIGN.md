# 차트 중심 모의투자 화면 설계

대시보드의 캔들 차트를 재사용하고 오른쪽에 운용 설정을, 하단에 포지션·체결·주문·신호 결과를 배치한다. 처음 열면 보유 현황을 볼 수 있다.

| ID | 요구사항 |
| --- | --- |
| P1 | 상단에 모의투자 모드, 세션 상태, 업데이트 시간, 일일 손실 한도와 가상 자산·누적 수익률을 표시한다. |
| P2 | 선택 종목의 확정 봉 위에 세션의 실제 모의 매수·매도 체결을 실행 시각 기준으로 표시한다. 차트에 포함되지 않은 체결은 체결 탭에 남긴다. |
| P3 | 기존 시작·설정 반영·일시정지·초기화·새로고침을 제공한다. 초기화는 확인을 받고 요청을 중복 실행하지 않으며 실패 원인을 노출한다. 설정 반영은 기존 API 동작대로 세션을 시작한다고 명시한다. |
| P4 | 현재 보유는 엔진 스냅샷의 수량·평균 단가·현금에서 읽는다. 목표 비중은 보유와 분리해서 전략 탭에 표시한다. 체결은 원장의 실행가·수량·수수료·실현 손익을 사용한다. |
| P5 | 주문 상태와 거부 사유, 전략·데이터 품질 상태, 참고 신호와 검증 표본, 기존 알림 미리보기와 세션 메모를 제공한다. |

기존 `GET /api/paper`에 화면 표시용 보유·현금, 갱신 시각, 일일 손실 한도를 추가한다. 이전 세션에 엔진 스냅샷이 없으면 보유 미확인으로 표시한다. 전역 신호 결과는 모의투자 주문 성과와 구분해 표기한다.

검증 범위는 기존 페이퍼 관련 테스트, 화면용 응답의 이전 세션 호환성, 브라우저의 종목·기간·탭 전환과 읽기 전용 새로고침이다. 모의투자 제어는 로컬 브라우저에서 세션에 영향을 주지 않는 범위로 검증한다. CI와 일반 Next.js 빌드 통과 후 develop에 merge commit으로 병합하고 두 화면을 데스크톱에서 캡처한다.
