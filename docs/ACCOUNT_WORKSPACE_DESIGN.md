# 계정 작업 화면 설계

상단 자산 요약, 중앙 포지션과 사용 가능·사용 중 잔액, 우측 인증 조회, 하단 가상 계정과 대기 주문을 기존 다크 터미널 스타일로 조합한다.

- A1. 비공개 계정은 웹훅 토큰을 입력하고 요청 버튼을 누른 경우에만 기존 선물 계정 API를 호출한다. 토큰은 요청 시 읽고 즉시 입력란을 비우며 브라우저 저장소에 기록하지 않는다. 응답 숨기기로 화면의 스냅샷을 지울 수 있다.
- A2. 잠김, 조회 중, 조회 성공, 부분 성공, 실패를 구분한다. 실패한 항목과 정상 응답의 0을 구분하고 응답 시각을 표시한다. 비공개 거래소 오류는 원문 대신 항목별 안전한 안내로 표시한다.
- A3. 비공개 포지션·미체결 주문은 별도 내역, 모의투자는 가상 자산·성과·현재 보유를 별도 영역에서 표시한다. 자격증명 보관함은 저장 상태를 표시하며 연결 결과는 요청 응답으로 판단한다.

계정 요약의 부분 응답과 0·미조회 구분을 테스트한다. 데스크톱에서 모의투자 데이터, 잠김 상태, 탭 탐색을 검증한다. 실제 거래소 계정 조회는 기존 제외 범위를 따른다. 일반 빌드와 CI를 통과하면 일반 머지한다.
