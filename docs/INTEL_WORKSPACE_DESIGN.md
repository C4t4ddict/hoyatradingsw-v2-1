# 시장 인텔리전스 작업 화면 설계

TradingView의 뉴스와 차트 배치를 참고한다. 상단에 종합 방향과 데이터 상태, 중앙에 종목·기간을 전환하는 확정 4시간봉, 우측에 선택 가능한 뉴스, 하단에 모델 및 수집 상세를 배치한다.

| ID | 완료 조건 |
| --- | --- |
| I1 | BTC·ETH·SOL 차트에서 필터에 맞는 뉴스 관측 시각을 표시한다. 뉴스 선택으로 해당 봉을 확인한다. 해당 기간에 확정 봉이 없으면 그 상태를 표시한다. 뉴스는 시장 공통 이벤트로 표시한다. |
| I2 | 기존 상위 뉴스에 주제·출처 필터를 제공한다. 한국어 제목, 원문 제목·링크, 발행 시각과 관측 시각, 상승·하락 점수를 조회한다. 필터 결과 없음과 요청 실패를 구분한다. |
| I3 | 신호 품질·가중치·ML 검증 표본과 모델 준비 상태를 유지한다. 뉴스 학습과 과거 패턴 학습을 탭으로 나누고 모델별 기준과 차단 사유를 확인한다. 검증되지 않은 확률은 화면에 수치로 표시하지 않는다. |
| I4 | 브리핑 갱신 시각, 정상 응답 수, 실패 및 시간 초과 출처와 기존 캐시 사용 여부를 명시한다. |

기존 `/api/intel`의 브리핑과 ML 데이터를 사용한다. 필터는 화면에 받은 뉴스에만 적용하며 종합 점수는 전체 브리핑 기준이다. 원문 링크는 HTTP(S)만 사용한다. 차트 선택 검증과 뉴스 필터 경계는 관련 테스트만 실행하고, 데스크톱에서 필터·선택·탭을 확인한다. CI 통과 후 develop에 일반 머지한다.
