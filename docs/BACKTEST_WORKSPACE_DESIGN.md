# 백테스트 작업 화면 설계

TradingView의 차트와 전략 테스트 결과 탭을 참고한다. Hoya의 공용 트레이딩 화면과 일관되게 상단 성과, 중앙 결과 차트, 우측 검증 조건, 하단 상세 기록을 배치한다.

| ID | 완료 조건 |
| --- | --- |
| B1 | 기존 종목·시장·시간봉·전략·기간·비용·방향·레버리지 입력을 유지한다. 날짜는 KST 기준으로 초기화한다. 실행 중 중복 제출을 차단하고, 입력 변경 또는 실패 후에도 마지막 성공 결과의 조건을 표시한다. |
| B2 | 자산 차트에서 전략과 동일 비용 매수 후 보유 기준을 비교하고, 낙폭 차트로 전환할 수 있다. 시간축은 KST, 가격축은 USDT, 낙폭축은 %로 표시한다. 차트 포인터와 키보드로 값을 조회한다. |
| B3 | 수익률·시장 대비 성과·최대 낙폭·Sharpe·거래 수를 상단에 표시한다. 하단 거래·성과·데이터 탭에서 진입·청산 및 비용과 출처를 확인한다. |

기존 백테스트 API의 `equity_curve`에 `benchmark_equity`, `drawdown_pct`를 추가한다. 비교 기준은 기존 최종 매수 후 보유 수익률 계산과 동일한 진입·청산 비용을 사용한다. 시각별 종가는 캔들 타임스탬프로 연결한다. 낙폭은 초기 자산과 전체 자산 곡선의 고점으로 산출한 뒤 기존 응답 한도 내에서 샘플링한다. 기존 전략·체결·성과 값과 주문 경로를 유지한다.

검증은 시계열 비용·낙폭 일치와 기존 백테스트 관련 테스트, 로컬에서 실제 공개 시세를 사용한 실행·차트·상세 탭 전환으로 한정한다. CI 통과 후 develop에 일반 머지한다.
