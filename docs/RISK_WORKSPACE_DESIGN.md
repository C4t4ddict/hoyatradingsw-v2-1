# 위험 관리 작업 화면 설계

기존 트레이딩 화면의 상단 상태 바, 중앙 데이터 패널, 우측 요약, 하단 상세 탭을 적용한다. 위험 화면에는 정책과 현재 세션 데이터를 사유·단위와 함께 표시한다.

- R1. 상단에 현물·선물 위험 보호, 최대 레버리지, 주문 모드, 모의투자 낙폭을 표시한다. 값이 없으면 미확인으로 표시한다.
- R2. 중앙에서 일일 손실, 연속 손실, 보유 종목 수, 레버리지, 매도 허용을 현물과 선물 간 비교한다. 우측은 별도로 모의투자 일일 손실 한도, 대기 주문, 세션 시각, 차단 사유를 표시한다.
- R3. 하단 탭은 주문 실행 정책과 모의투자 진단을 제공한다. 시간대와 USDT·%·배수를 함께 표기한다. DRY_RUN 강제가 확인되면 실거래 제어 상태와 구분한다.

기존 읽기 전용 위험 및 모의투자 API를 재사용한다. 일반 빌드 및 데스크톱에서 정책·진단·누락 상태 확인 후 CI를 통과해 일반 머지한다.
