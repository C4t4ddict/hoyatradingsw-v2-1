# 운영·보안 작업 화면 설계

상단에 수집기·모의투자 작업자·원장·경보·주문 모드를, 가운데에 수집 품질과 작업 상태를, 우측에 설정 토큰 및 실거래 제어를 배치한다. 상세 기능은 경보, 수집 로그, 세션 평가, 신호 결과, 감사, 자격증명 탭으로 분리한다.

- O1. 기존 15초 수집 갱신과 수집 재개·일시정지·실패 재시도·모의투자 재개를 유지한다. 상태 API 실패와 정상 0건을 구분하고 KST로 표시한다. UTC로 집계한 일별 기록은 UTC로 표시한다.
- O2. 작업자·원장 상태, 활성/위험 경보, 설정과 감사 이력, 모의투자 평가 및 그림자 신호를 표시한다.
- O3. 기존 설정 토큰과 별도의 두 번 확인, 5분 확인 만료, 240분 활성화, 주문 상한, 모의투자 전환을 유지한다. 화면에서 기한 만료나 토큰 변경 시 이전 확인을 무효화한다. 요청 실패와 요청 성공 후 상태 갱신 실패를 구분한다.
- O4. 자격증명 암호화 저장, 백업, CSV 내보내기, 일간 리포트 전송을 기존 경로로 제공한다. 입력한 값은 설정 상태·메시지·감사 화면에 표시하지 않는다.

기존 API를 유지한다. 만료·잠김 제어의 회귀 테스트를 추가한다. 브라우저는 읽기 전용 상태·탭·새로고침과 토큰 없는 버튼 상태를 검증한다. 범위 테스트 및 CI 통과 후 일반 머지한다.
