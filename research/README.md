# Crypto strategy research

This directory contains a research-only, reproducible comparison of automatic
crypto-investment strategies. It never reads account credentials or places
orders.

## Method

- Binance USD-M public BTC, ETH, and SOL 4-hour OHLCV and funding history
- Signals calculated at bar close and applied from the next bar open
- Turnover costs, slippage assumptions, and position-side funding included
- Maximum absolute exposure of 1.0x
- Parameter robustness, cost sensitivity, and a 2024-current holdout

Cached market data is written under `data/research_cache/` and is intentionally
excluded from Git. Tables and charts under `research/output/` are derived
artifacts generated by the study.

## Run

From the repository root:

```powershell
.\.venv\Scripts\python.exe -m pip install -r research\requirements.txt
.\.venv\Scripts\python.exe research\crypto_strategy_backtest.py
.\.venv\Scripts\python.exe research\build_crypto_strategy_notebook.py
```

On macOS or Linux:

```bash
./.venv/bin/python -m pip install -r research/requirements.txt
./.venv/bin/python research/crypto_strategy_backtest.py
./.venv/bin/python research/build_crypto_strategy_notebook.py
```

The first run downloads public market data and can take several minutes. Later
runs use the local cache unless `run_study(refresh=True)` is requested.

## Safety limits

The study is not a live-trading engine or a guarantee of future returns. Bar
data cannot reproduce order-book depth, partial fills, exchange outages,
delistings, taxes, or an account's exact fee tier. A strategy must pass paper
trading and live slippage monitoring before any capital is allocated.
